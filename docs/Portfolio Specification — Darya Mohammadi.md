# Darya Mohammadi — Full-Stack Engineer Portfolio

## 1. Portfolio Goal

Build a professional personal portfolio for **Darya Mohammadi**, positioned as a:

> **Backend-focused Full-Stack Engineer**

The portfolio should communicate one clear idea:

> **I build scalable web systems, not just websites.**

The primary goal is to attract:

1. Full-Stack Engineering opportunities
2. Backend Engineering opportunities
3. Freelance / real-world software projects
4. International / European engineering roles

The portfolio should make a recruiter or engineering manager understand within the first 20–30 seconds that Darya is:

> **A real Full-Stack Engineer with strong backend expertise, system-design knowledge, database experience, and DevOps awareness.**
